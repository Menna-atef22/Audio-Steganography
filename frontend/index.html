How DWT + Spread Spectrum Works

📊 Discrete Wavelet Transform (DWT)

DWT decomposes audio signals into multiple frequency bands at different scales. This hierarchical decomposition isolates signal features and provides an ideal domain for hiding information:

  • Approximation coefficients (low-frequency)
  • Detail coefficients (high-frequency)
  • Multi-level decomposition for robustness

🌊 Spread Spectrum Embedding

Spread Spectrum distributes the secret message across multiple frequency bands, reducing the signal amplitude needed per bit:

  • Message spread across bands
  • Reduced detectability
  • Improved noise resilience
